# Матрицы комплексных чисел

Небольшая консольная программа на Java для практической работы. Она позволяет вводить матрицы, элементы которых — комплексные числа, и выполнять над ними основные операции.

## Что умеет программа

В меню можно выбрать одну из операций:

- сложить две матрицы;
- умножить одну матрицу на другую;
- разделить матрицы;
- транспонировать матрицу;
- найти определитель.

Если для выбранной операции не подходят размеры матриц, программа сообщит об ошибке. Определитель считается только для квадратной матрицы.

## Как запустить

Нужна установленная Java (JDK 8 или новее). Дополнительные библиотеки не используются.

Откройте терминал в папке проекта и выполните:

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```

В Windows команды можно запустить из CMD или PowerShell.

## Как вводить числа

Каждый элемент вводится парой чисел: сначала действительная часть, затем мнимая. Например:

- `3 0` — это `3`;
- `0 1` — это `i`;
- `3 -2` — это `3 - 2i`.

Дробные числа вводятся через точку, например `1.5 -0.25`.

## Как работает деление

У матриц нет единственного общепринятого варианта деления, поэтому здесь операция `A / B` реализована как `A * inverse(B)`, то есть умножение матрицы A на обратную к B. Для этого B должна быть квадратной и иметь обратную матрицу. Размеры A и B также должны подходить для умножения.
